# Survival++

> 关于游戏技术选项控制的 Minecraft Neoforge 模组

## 主要特性

### 广播死亡位置

> 当玩家死亡时，将死亡位置发送到聊天栏
* 启用: `/rg broadcastDeathPosition true`

### 简单的游戏内计算器

> 游戏内的简单计算器
* 启用: `/rg simpleInGameCalculator true`
* 用法: 
  * `=1+1`
  * `=1+1*2`
  * `=1+1*2/3`
  * `=1+1*2/3^4`

### 创造玩家无碰撞检测
> 创造玩家可以穿过方块
* 启用: `/rg creativeNoClip true`
